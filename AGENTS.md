# Project constraints

Preserve the user's keymap, left/right 3-second boot keys, working split roles,
pointing paths and peripheral LED behavior. v4 changes OLED only.
Use the actual original englmaxi dongle UI, Mac modifier symbols, and D/L/R batteries.
Do not add an Apple logo, a new dashboard, or swap Ctrl/GUI in the keymap.
Never present a host fixture test as an ARM/Zephyr build or a physical OLED test.
Do not ask the user to reset working BLE bonds for a display-only update.
