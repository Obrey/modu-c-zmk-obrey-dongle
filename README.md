# MODU-C + 동글 v6 — 좌우 배터리 상태 확인 기능

**전체 소스입니다. 실제 ARM 빌드/기판 테스트 미완료. 정확한 잔량 보정 완료본이 아닙니다.**

v5의 입력·트랙볼·LED·Mac 수정키·화면 테마·키맵을 유지하고, 좌우 키보드의
센서 측정 퍼센트/전압/성공 여부를 기존 BLE 연결로 동글에 전달하는 기능을 추가했습니다.
이전과 달리 미수신/측정 오류를 실제 0%와 구분합니다. ADC 핀이나 분압비는 변경하지 않았습니다.

## 설치

이번에는 **왼쪽 `modu_left.uf2`, 오른쪽 `modu_right.uf2`, 동글 `modu_dongle_oled.uf2`**
모두 같은 새 빌드로 업데이트해야 합니다. 연결이 되는 상태이므로 settings_reset은 사용하지 않습니다.
전체 소스를 GitHub 저장소 같은 경로에 덮어쓰고 빌드 성공 후 위 세 파일을 적용합니다.
자세한 설명은 [설치 설명](docs/FLASHING_KO.md)을 확인하세요.

## 포함된 변경

- 좌우 측정 결과를 제공하는 읽기 전용·암호화 BLE 서비스.
- 동글의 주기적 재조회 및 펌웨어가 알려주는 L/R 식별.
- 정상 퍼센트 / 미수신 / 센서 오류 / 오래된 값 / 연결 해제 구분.
- 0% 또는 확인이 필요한 전압이면 해당 행에 전압도 교대 표시.
- 기존 기본 BAS 보고 경로와 화면 배치/글꼴/기호 유지.

반드시 `docs/FLASHING_KO.md`입니다.
