# MODU-C v11 충전 모드

- 사용 중 키 입력, 트랙볼, 동글 BLE 연결은 v10과 동일한 정상 성능을 유지합니다.
- 좌/우 키보드의 nRF52840 VBUS 감지를 직접 읽어 USB 전원 연결 여부를 판별합니다.
- USB 전원 연결 중에는 상태 LED를 끄고, 배터리 진단 샘플을 10분 간격으로 줄입니다.
- OLED에는 좌/우 원시 전압 대신 상대 퍼센트 또는 `CHG`만 표시합니다. 원시 전압은 텔레메트리에 계속 보존됩니다.
- 충전 전압, 충전 전류, 레귤레이터, 배터리 ADC 비율은 변경하지 않습니다.
- v10의 10분 Deep Sleep 설정은 그대로 유지합니다. 즉 실제로 입력 중일 때는 절전되지 않고, 10분 동안 아무 입력도 없으면 기존 v10처럼 Deep Sleep을 시도합니다.
- 제작자 PMW3610 드라이버는 이 하드웨어에서 polling이 필요할 수 있다고 명시합니다. 따라서 v10/v11의 Deep Sleep wake 동작은 실물에서 반드시 검증해야 합니다. 깨우기가 불안정하면 이전 안정 펌웨어로 되돌리세요.

## 키맵
`config/modu.keymap`은 사용자가 수정한 MODU-C 배열을 유지합니다. 좌측 `5`를 3초 홀드 후 `1`, 우측 `6`을 3초 홀드 후 `0` 부트 동작도 유지합니다.
