# v3 -> v4 변경

요청: 기존 Corne 화면을 유지하고 Windows 수정키 표시를 Mac 기호로 바꾸며 D/L/R 배터리 표시.

- 원래 화면 모듈 복구. 새 대시보드/로고 삭제.
- 실제 키맵, 좌우 LED, 트랙볼 전달, 페어링 설정 변경 없음.
- 기존 화면의 상단 배터리 위젯만 MODU의 실제 좌우 식별과 연결 상태에 맞게 교체.
- 초기화 시 NULL 이벤트가 들어가는 원본 HID 위젯을 빌드 사본에서 보호.
- ZMK는 기존 동작 버전 고정. 화면의 새 배터리 설정 이름만 빌드 사본에서 구버전 이름으로 변환.
- OLED 모노 테마 활성화, 100% 단색 버퍼 및 전체 갱신, 32 KiB LVGL 전용 메모리.
- 흰 화면의 실물 원인/해결 여부는 미확정. ARM 컴파일은 미실행.
