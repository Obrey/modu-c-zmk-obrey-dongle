# 변경 내역 — 2026-09-15

## 기준

개발자 기본 ZIP의 manifest, 라이선스, 메타데이터 및 패키징 도구를 바탕으로 구성했습니다.
활성 키맵은 사용자가 먼저 올린 커스텀 배열에 3초 부트키 수정본을 적용한 버전입니다.
제조사 기본 배열로 되돌린 버전이 아닙니다.

## 키맵

기존 7개 레이어의 일반 배열을 유지하고, 기본 레이어의 5/6만 전용 hold-tap으로 바꿨습니다.
Boot Left/Boot Right 2개 레이어를 끝에 추가했습니다.
기존 좌우 지정 부트 콤보 C 모듈은 제거했고, 마지막 확인 키의 일반 `&bootloader`를 사용합니다.
다른 홈열 모드키 설정이나 게임 레이어 숫자키를 3초로 바꾸지 않았습니다.

## 하드웨어

좌우는 기존 `modu_left`/`modu_right` 쉴드를 그대로 쓰고, CMake에서 peripheral 역할을 강제합니다.
왼쪽의 중앙 장치 역할 및 USB HID 출력은 끕니다. USB 부트로더 코드를 제거하는 뜻은 아닙니다.
원본 GPIO, 폴링 설정, 방향 선택 센서, 엄지키 매핑, PMW3610 보정은 원본 모듈에 남습니다.

`config/dongle/*.overlay`가 원본 쉴드 뒤에 추가됩니다.
왼쪽은 사용하지 않는 input-split ID 0을 끄고 자기 트랙볼을 ID 1로 보냅니다.
오른쪽은 기존 ID 0을 유지하고, 실제 센서가 연결되지 않은 ID 1을 꺼 둡니다.
동글은 두 ID를 받아 기존 이름의 두 input listener로 연결합니다.
좌우 모두 자신의 local listener를 꺼서 peripheral에서 HID 처리를 중복하지 않습니다.

동글의 matrix transform은 제공된 `config/modu.json`의 67개 위치에서 생성하고 원본과 대조했습니다.
동글에는 키보드의 실제 GPIO/SPI/배터리/상태 LED 노드를 복사하지 않았습니다.

## 동글 화면

제공된 Corne 파일에서 OLED 칩, 주소, 핀, 방향 설정을 참조합니다.
커스텀 DYA 화면 대신 기본 ZMK 상태 화면입니다. 가로 129는 128로 조정했습니다.
화면 없는 버전도 포함합니다. 포크 전용 부가기능과 Studio는 이번 범위에 넣지 않았습니다.

## 빌드/패키징

6개 대상 이름을 일관되게 사용하고, MODU 보드와 동글 보드의 리셋 결과를 구분했습니다.
`.github/workflows/build.yml`에 새 `local-modules/**` 경로와 전체 구성 테스트를 연결했습니다.
ZMK와 제조사 소스의 직접 revision은 원본대로 유지합니다.

루트 `zephyr/module.yml`을 새로 추가하지 않은 것은 의도적입니다.
고정한 재사용 워크플로우가 루트 모듈 존재 여부에 따라 작업 경로를 바꾸므로,
원본과 동일한 `${GITHUB_WORKSPACE}/modu-c-firmware` 경로를 유지합니다.
추가 동글 쉴드만 명시적인 별도 모듈로 전달합니다.

## 검증 제한

호스트 정적 검사와 패키징 시험을 실행했으며 펌웨어 컴파일 및 실물 테스트는 미실행입니다.
시험에서 생성한 UF2는 합성 데이터이며 설치 대상이 아닙니다. 소스 ZIP에는 포함하지 않습니다.
