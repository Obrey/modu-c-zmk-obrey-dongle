# MAC v3 변경 내역

- 무선 역할, ms88sf3/nrf52840 및 nice_nano/nrf52840/zmk 보드 선택, 양쪽 PMW3610 전달 경로는 유지.
- 동글 공통 키맵 입력을 명시하고, 생성 Devicetree에 대한 67자리/좌우 부트키 구조 검사를 추가.
- 기존 커스텀 키맵과 대조한 결과 원래 7개 레이어에서 바뀐 것은 Base의 5·6 부트 준비 동작뿐임을 기록.
- keymap settings storage와 Studio를 명시적으로 꺼, 이전 저장 키맵이 이 소스를 덮지 않도록 함.
- OLED 흑백/LVGL 버퍼 설정 보완. 별도 화면 큐 및 4KB 스택, 16KB LVGL 풀 사용.
- 작은 Mac 형태 아이콘, MAC v3, 호스트 USB/BT 상태, 좌우 실제 배터리/링크, 동글 전원, 현재 레이어, 키맵 지문 화면 추가.
- 좌우를 최초 접속 순서로 가정하지 않음. 실제 키 위치와 BLE 주소로 학습해 own settings namespace에 저장.
- 배터리 0%, 아직 값을 받지 못함, 연결 끊김을 별도로 표현. 동글 배터리 존재 여부는 기본 false.
- 양쪽 기존 LED 드라이버 비활성화 후 split peripheral 링크 기준 LED 사용. 제조사 PWM 극성/좌우 색상 채널 유지.
- 일반 설치 UF2 3개를 결과물 최상위에 두고 headless는 fallback/, 초기화용은 reset/로 분리.
- 호스트 C 테스트·UI 네이티브 대역 시뮬레이션 추가. ARM 및 하드웨어 검증으로 오인하지 않도록 결과를 명시.

이전 OLED 먹통의 직접 원인과 사용자의 실제 적용 키맵 불일치 원인은 아직 실물에서 확정하지 않았습니다.
