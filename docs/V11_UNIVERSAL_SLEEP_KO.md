# v11 충전 집중 / 범용 Deep Sleep

## 적용 대상
- `modu_left.uf2`
- `modu_right.uf2`

동글 펌웨어는 기존 전원 정책을 유지합니다.

## 동작
- 30초 무입력: 기존 ZMK Idle. 상태 LED가 꺼지고 배터리/상태 작업 빈도가 줄어듭니다.
- 약 2분 총 무입력: 좌/우 키보드가 `sys_poweroff()` System OFF로 들어갑니다.
- **충전선 연결 여부와 무관하게** 동일하게 동작합니다. USB/VBUS가 꽂혀 있어도 2분 무입력이면 System OFF를 시도합니다.
- 깨우기: 키보드 물리 키를 한 번 누릅니다. BLE 재연결 때문에 첫 키는 깨우기용으로 소비되거나 입력이 늦게 보일 수 있습니다.

## 물리 스위치 OFF + USB 충전
물리 스위치가 배터리 쪽만 끊고 USB가 MCU에 전원을 공급하는 하드웨어라면, OFF 상태에서도 USB 때문에 보드가 켜질 수 있습니다. v11은 그 경우에도 입력이 없으면 약 2분 뒤 System OFF로 보내 키보드 측 소비를 최소화합니다.

단, 펌웨어는 물리 스위치 위치를 직접 읽지 못하므로 **스위치를 내리는 순간 즉시** 모드가 바뀌는 것은 아닙니다. USB로 보드가 살아 있다면 무입력 타이머를 통해 자동으로 들어갑니다. USB도 없고 스위치가 실제 전원을 끊으면 하드웨어적으로 바로 꺼집니다.

## 충전에 대한 의미
이 기능은 충전 IC의 전류를 올리거나 충전 회로를 바꾸지 않습니다. BLE/센서/MCU가 소비하는 전력을 System OFF 수준으로 줄여, 충전 중 키보드가 옆에서 소비하는 몫을 줄이는 목적입니다. 실제로 OFF 스위치 상태에서 배터리 충전 경로가 유지되는지는 기판 회로에 따라 달라집니다.

## 구현 방식
ZMK 기본 자동 Deep Sleep은 USB 전원이 감지되면 System OFF 진입을 건너뜁니다. v11은 ZMK Idle 이벤트를 기준으로 별도 지연 작업을 걸고, 총 무입력이 120초가 되면 USB 상태를 검사하지 않고 `zmk_pm_suspend_devices()` 후 `sys_poweroff()`를 호출합니다.

기존 v10의 10분 Deep Sleep 설정은 배터리 사용 시 fallback으로 그대로 남겨 둡니다. v11 경로가 먼저 약 2분에 동작합니다.

## 주의
- 트랙볼만 움직여서 System OFF에서 깨우는 것은 보장하지 않습니다. 키를 눌러 깨우세요.
- 실물에서 USB가 꽂힌 상태의 System OFF 유지 여부와 실제 충전 속도 개선 폭은 하드웨어 검증이 필요합니다.
- 키맵, 좌/우 3초 부트 키, BLE bond, 트랙볼 경로는 변경하지 않았습니다.
