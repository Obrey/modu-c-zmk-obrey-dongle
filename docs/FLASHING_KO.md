# v3 사용 중이라면: 이번에는 동글 하나만 업데이트

1. 이 저장소 전체 소스를 GitHub의 같은 경로에 덮어쓰고 커밋합니다.
2. 새 `Build MODU-C + Dongle` 빌드가 성공한 결과물 `modu-c-dongle-firmware`를 받습니다.
3. 현재 사용 중인 OLED 동글을 부트로더로 진입시킨 뒤 **`modu_dongle_oled.uf2`**를 복사합니다.
4. 왼쪽·오른쪽 키보드는 그대로 켜둡니다. `settings_reset`은 넣지 않습니다.

정상 사용 파일의 의미:
- `modu_dongle_oled.uf2`: 화면 동글. **이번 업데이트에서 적용할 파일**.
- `modu_left.uf2`, `modu_right.uf2`: 좌우 키보드. 이미 v3를 사용한다면 이번에는 재설치 불필요.
- `fallback/modu_dongle.uf2`: 화면 없는 동글. 화면을 끄는 별도 대체 펌웨어.
- `reset/*`: 설정 초기화용. 일반적인 화면 수정 업데이트에서 사용하지 않음.

기존 키맵과 부트키는 바꾸지 않았습니다.
동글의 소프트웨어 부트로더 조작이 없으면 기존에 사용하던 동글의 물리 부트 진입 절차를 사용합니다.
좌우 키보드용 `5 -> 1`, `6 -> 0` 조작은 **동글을 재부팅하는 조작이 아닙니다**.

## 화면

원래 Corne 동글 화면 구성을 쓰며 수정키만 Mac 기호로 표시합니다.
애플 로고, MAC v3 제목, 키맵 해시 표시는 없습니다.
배터리 영역은 위부터 D(동글), L(왼쪽), R(오른쪽)입니다.
`--%`는 아직 배터리 값 또는 좌우 식별 정보를 받지 못한 상태입니다.
좌우 식별이 아직 없으면 빈 메모장에서 왼쪽 `1`, 오른쪽 `0`을 각각 **짧게 한 번** 누릅니다.
v3에서 저장한 좌우 식별 정보가 있으면 그대로 재사용합니다.
`OFF`는 식별한 해당 키보드가 지금 연결되지 않은 상태입니다.
배터리 값이 실제 0%이면 `0%`를 표시하고 숨기지 않습니다.

D는 보드가 보고한 센서값이며 실제 배터리와 올바른 측정 회로가 있어야 잔량으로 해석할 수 있습니다.
USB 전용 동글에는 `CONFIG_MODU_DONGLE_HAS_BATTERY=n` 설정을 사용합니다.

## 입력은 되는데 화면이 계속 흰색이면

연결된 세 장치의 설정 초기화를 반복하지 않습니다. 입력이 되는 상태를 유지합니다.
이 경우 새 빌드의 OLED `.config`, 디바이스트리, 화면 초기화 로그 또는 실물 패널 확인이 필요합니다.
이번 소스는 실물 화면에서 검증된 파일이 아닙니다.
