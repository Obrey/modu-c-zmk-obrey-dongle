# MODU-C + 동글 설치 안내

## 먼저 확인

이 안내는 이 저장소의 Actions가 **실제로 성공해 생성한 결과 UF2**에 적용합니다.
소스 검사 통과만으로 하드웨어 동작까지 확인되는 것은 아닙니다.
기존에 동작하는 좌·우·동글 펌웨어를 별도 보관하십시오.

**초기화 펌웨어를 넣기 전에, Bluetooth 연결이 끊겨도 각 장치를 다시 부트로더로 보내는
기존 하드웨어 복구 방법을 반드시 확보하십시오.** 이 저장소의 3초 부트키는 실행 중인 정상
키맵과 동글 연결이 있어야 작동합니다. settings_reset 펌웨어에는 이 키맵이 들어 있지 않습니다.
MODU-C의 미확인 핀을 단락하거나 전원 핀을 건드리지 마십시오.
제조사가 확인한 버튼/리셋 방식만 사용하십시오.

## 결과 파일 구분

| 파일 | 올리는 장치 | 용도 |
|---|---|---|
| `modu_left.uf2` | MODU-C 왼쪽 | 왼쪽 입력 전송용 정상 펌웨어 |
| `modu_right.uf2` | MODU-C 오른쪽 | 오른쪽 입력 전송용 정상 펌웨어 |
| `modu_dongle.uf2` | 기존 Corne 동글 | 화면 없는 중앙 동글 펌웨어 |
| `modu_dongle_oled.uf2` | 같은 동글 | 기본 ZMK OLED 화면 포함 중앙 펌웨어 |
| `settings_reset_modu.uf2` | MODU-C 좌우 각각 | MODU 보드용 설정·페어링 초기화 |
| `settings_reset_dongle.uf2` | 동글만 | nice!nano 동글용 설정·페어링 초기화 |

**동글 버전 2개는 대안입니다. 동글에 둘 다 넣는 것이 아닙니다.**
**두 리셋 파일도 서로 바꿔 쓰면 안 됩니다.** 칩이 같은 nRF52840이어도 보드 구성이 다릅니다.

## 최초 동글 구성으로 바꿀 때

기존 연결 구조의 본딩 정보는 새 펌웨어 파일만 올려도 남을 수 있습니다.
공식 ZMK 동글 안내대로 **좌우와 동글 모두 설정 초기화를 한 번 진행한 뒤 정상 펌웨어를 넣는**
절차가 필요합니다. 이 과정은 저장된 연결과 설정을 지웁니다.

각 장치를 기존 방식으로 부트로더에 진입시키고, 자기 보드에 맞는 settings_reset 파일을 복사합니다.
초기화 펌웨어가 부팅되어 실행된 것을 확인한 뒤, 연결에 의존하지 않는 복구 방법으로 다시
부트로더에 진입하고 정상 파일을 넣습니다. 초기화 펌웨어를 넣은 상태로 끝내지 마십시오.
공식 초기화 절차는 아래 문서를 확인하십시오.

세 장치에 정상 펌웨어를 설치한 뒤, 동글을 컴퓨터의 USB에 연결하고 좌우 키보드를 켭니다.
근처에 다른 ZMK 중앙 장치가 있으면 혼선을 피하도록 잠시 꺼 두십시오.
운영체제에 좌우 키보드를 각각 Bluetooth 키보드로 등록하는 구성이 아닙니다.
초기 검증에서는 USB 동글 출력을 사용하십시오.

## 설치 후 확인할 항목

1. 왼쪽 키, 오른쪽 키, 엄지키의 위치가 원래 배열과 일치하는지 확인합니다.
2. 좌우 트랙볼을 각각 굴려 이동 방향과 원래 방향 선택 기능을 확인합니다.
3. 기본 레이어에서 짧은 `5`, `6`, `51`, `60` 입력이 의도대로 되는지 확인합니다.
4. 왼쪽 5만 3초 이상 누른 후 1을 눌러 **왼쪽만** 부트로더에 들어가는지 확인합니다.
5. 왼쪽 펌웨어를 복구한 뒤 오른쪽 6만 3초 이상 누른 후 0을 눌러 **오른쪽만** 들어가는지 확인합니다.
6. 동글 화면을 쓰는 버전은 화면·출력 상태·레이어 표시를 따로 확인합니다.

3초 조작은 새 펌웨어를 먼저 설치해야 쓸 수 있습니다.
키보드를 USB 데이터 케이블로 연결해야 부트로더 저장장치가 컴퓨터에 보일 수 있습니다.
동글이 없거나 연결이 끊겼을 때의 복구에는 새 키맵 조작을 의존하지 마십시오.

## 연결이 안 될 때

현재는 좌우 모두 peripheral이므로 동글 없이 단독 PC 연결로 돌아가지 않습니다.
원래 동글 없는 구조로 돌아가려면 보관해 둔 이전 펌웨어와 해당 구조의 초기화 절차가 필요합니다.
먼저 세 장치가 모두 이 저장소의 같은 빌드 구성인지, 리셋 파일을 보드에 맞게 사용했는지,
정상 펌웨어를 다시 넣었는지 확인하십시오. 무작정 다른 보드용 UF2를 복사하지 마십시오.
