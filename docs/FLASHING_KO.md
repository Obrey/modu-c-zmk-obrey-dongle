# MAC v3 설치 — 평소에는 세 파일만

이 문서가 들어 있는 `modu-c-dongle-firmware` 결과물의 **최상위 UF2 세 개**를 사용합니다.

| 장치 | 파일 |
|---|---|
| 모두 C 왼쪽 | `modu_left.uf2` |
| 모두 C 오른쪽 | `modu_right.uf2` |
| 코르네 동글 | `modu_dongle_oled.uf2` |

각 장치를 기존 방식으로 부트로더에 진입시킨 뒤, 그 장치의 USB 드라이브에 해당 파일만 복사합니다.
모두 C용 파일과 nice_nano 동글용 파일을 서로 바꾸지 마세요.
이미 headless 동글로 입력되는 상태에서는 `reset/` 폴더의 초기화 파일을 쓰지 않습니다.
동글·좌우 모두 같은 새 실행의 결과물을 사용합니다. 특히 LED 변경에는 좌우 펌웨어 업데이트가 필요합니다.

화면에 `MAC v3`와 `0 Base`가 보이면 새 화면입니다.
첫 설치 때 `press a key`가 나오면 빈 메모장에서 왼쪽 `1`, 오른쪽 `0`을 각각 짧게 누르세요.
좌우 판별 정보를 저장합니다. L/R의 ON은 각 키보드→동글 연결, 맨 위 USB/BT 표시는 동글→컴퓨터 연결입니다.
D행의 기본값 `USB POWER`는 동글 전원이며, 없는 배터리를 100%로 표시하지 않습니다.

`3 Game`일 때 왼쪽 맨 위 키를 한 번 누르면 `0 Base`로 돌아갑니다.
Base에서 왼쪽 `5`만 3초 누른 채 `1`, 오른쪽 `6`만 3초 누른 채 `0`이 각 부트로더입니다.
해당 키보드가 동글에 연결되어 있어야 이 소프트웨어 부트키가 전달됩니다.

## OLED에 문제가 생긴 경우

동글만 `fallback/modu_dongle.uf2`로 바꿔 화면 없는 버전으로 돌아갑니다.
그 상태에서는 동글 화면이 꺼져 있는 것이 정상입니다. 양쪽 펌웨어/페어링은 그대로 둡니다.
입력이 되는 상태를 잃지 않도록, 동작하던 이전 UF2도 별도로 보관하세요.

## reset 폴더는 복구가 필요한 경우만

`reset/settings_reset_modu.uf2`는 모두 C 양쪽의 초기화용입니다.
`reset/settings_reset_dongle.uf2`는 nice_nano 동글 초기화용입니다.
초기화는 페어링/저장 설정을 지우므로 이번 정상 업데이트 절차에는 포함되지 않습니다.
초기화 펌웨어는 정상 입력용이 아니며, 썼다면 부트로더에 다시 들어가 본래 장치용 펌웨어를 넣어야 합니다.

이 결과물은 GitHub Actions가 컴파일·링크한 파일이지만, 포장 성공만으로 실물 동작까지 보증되지 않습니다.
