# V9 MODU-C 실사용 배터리 게이지

이 버전은 기존 ZMK의 3.45~4.2V 퍼센트가 MODU-C 관측 범위와 맞지 않아 0%로 고정되던 문제를 **표시 레이어에서만** 개선합니다.

- 무선 사용 기준 0% 하한 기본값: **1.75V**
- 무선 사용 기준 100% 상한 기본값: **2.95V**
- 2026-09-30: L 1.76V / R 1.87V에서 동작
- 2026-10-01: L은 꺼짐, R 1.78V에서 이상 동작
- 따라서 1.75V는 셀 전압/보호회로 차단값이 아니라 **MODU-C 센서의 실사용 하한 근사치**입니다.
- 좌/우 USB 전원이 감지되면 잔량 대신 `CHG`를 표시합니다. 충전 중 3.3V대 값을 100% 계산에 섞지 않습니다.
- 전압 화면은 그대로 실제 센서 보고값을 표시합니다.
- 기존 BAS 퍼센트, ADC 설정, 충전회로, 부트로더, 키맵, 트랙볼, LED 전기 설정은 바꾸지 않습니다.

## 대략적인 기본 표시

- 2.95V 이상: 100%
- 2.80V: 약 88%
- 2.73V: 약 82%
- 2.64V: 약 74%
- 2.35V: 약 50%
- 1.87V: 약 10%
- 1.78V: 약 3%
- 1.75V 이하: 0%

이 값은 화학적 SOC가 아니라 MODU-C 실사용 상대 게이지입니다. 완충 후 USB를 뺀 안정값이 2.95V와 다르면 `modu_dongle_oled.conf`의 MAX 값만 조정할 수 있습니다.
