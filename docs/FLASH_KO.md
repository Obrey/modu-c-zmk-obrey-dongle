# 첫 동글 전환·펌웨어 갱신 안내

## 먼저 확보할 것

Actions에서 **세 정상 펌웨어와 두 초기화 펌웨어가 모두 빌드된 다음** 시작하세요.
정상 동작하던 MODU 왼쪽·오른쪽 UF2와 Corne 동글 UF2도 별도로 백업합니다.
MODU 두 쪽의 물리 리셋/부트로더 진입 방법과 동글의 물리 리셋 방법을 먼저 확인합니다.
새 키맵의 콤보는 새 펌웨어 설치 후 정상 연결되기 전에는 쓸 수 없습니다.

## 1회 전환: 먼저 세 장치의 연결 정보 초기화

기존 Corne 키보드는 꺼 두세요. 다른 ZMK 주변 장치와 잘못 짝지어지는 것을 피하기 위함입니다.
부트로더/초기화가 끝난 장치에는 일반 키 입력이 되지 않는 것이 정상입니다.

1. MODU 오른쪽을 부트로더로 넣고 `modu_settings_reset.uf2`를 복사합니다.
   실행되어 초기화가 완료될 시간을 주고, 정상 펌웨어를 넣기 전까지 꺼 둡니다.
2. MODU 왼쪽에도 **같은** `modu_settings_reset.uf2`를 적용하고 꺼 둡니다.
3. 동글에는 **별도 파일** `dongle_settings_reset.uf2`를 적용합니다.

각각 부트로더에 다시 들어가 정상 이미지를 넣어야 하므로,
**초기화 펌웨어 적용 후에도 키 콤보로 부트로더에 들어갈 수 있다고 가정하지 마세요.**
settings-reset 이미지는 Bluetooth와 일반 키맵을 사용하지 않습니다.
동글 초기화는 원래 Corne과의 연결 정보를 지웁니다.

## 정상 펌웨어 세 개 설치

| 장치 | 넣을 정상 파일 |
|---|---|
| MODU 왼쪽 | `modu_left_dongle.uf2` |
| MODU 오른쪽 | `modu_right_dongle.uf2` |
| USB 동글 | `modu_dongle.uf2` |

개별 장치에 USB **데이터** 케이블을 연결해서 해당 UF2만 복사하세요.
복사 중에는 전원을 끄거나 케이블을 분리하지 않습니다.
각 장치의 물리 리셋으로 부트로더에 다시 들어가 적용합니다.
정상 이미지가 모두 설치되면 동글은 PC에 USB 연결하고 MODU 양쪽 전원을 켭니다.
초기 연결을 기다린 다음 한쪽씩 문자·숫자·트랙볼을 시험합니다.

이 구성에서 PC와 직접 통신하는 본체는 동글입니다.
MODU 키보드 USB는 전원/부트로더 플래시 용도이며 정상 키입력의 USB 단독 대체 경로가 아닙니다.
Windows에 각각의 MODU 반쪽을 다시 페어링할 필요는 없습니다.
보통 USB 동글이 일반 HID 키보드/마우스로 보이면 됩니다.

## 연결 후 좌우 부트로더 콤보

Base 상태, 0.5초 정도 아무 키도 누르지 않은 뒤:

* 왼쪽 업데이트: 왼쪽에 USB 데이터 케이블 → `1+3+5` 동시에 → 왼쪽 UF2 드라이브 확인.
* 오른쪽 업데이트: 오른쪽에 USB 데이터 케이블 → `6+8+0` 동시에 → 오른쪽 UF2 드라이브 확인.

동글은 계속 꽂아 둡니다. 한쪽 설치와 재연결을 마친 뒤 다른 쪽을 진행하세요.
콤보가 인식되면 지정한 반쪽이 키 입력을 멈추는 것은 정상입니다.
해당 반쪽에 USB 데이터 연결이 없으면 부트로더에 들어가도 PC에 드라이브가 안 보입니다.

동글 자체 업데이트는 동글의 물리 리셋/기존 진입 방법을 사용합니다.
`135`, `680`으로 동글을 초기화하도록 만들지 않았습니다.

## 확인할 순서

1. PC에 동글만 USB 연결, MODU 양쪽은 배터리 전원 → 좌우 키 입력.
2. 왼쪽과 오른쪽 트랙볼을 각각 굴려 방향과 움직임 확인.
3. Base / Nav / Mouse / Game / FnMedia 전환, 게임 수정키/방향키 확인.
4. 양쪽 정상 연결 상태에서 한쪽 부트로더 콤보씩 시험.
5. 그 이후에 배터리 표시와 OLED 상태를 확인.

동글 OLED는 이전 Corne 맞춤 UI가 아니라 ZMK 기본 상태 화면입니다.
OLED에 배터리가 0으로 나오거나 값이 부정확해도 측정 회로가 고쳐진 것은 아닙니다.
이번 버전은 동글 자체의 가상 배터리 수치는 보고하지 않습니다.

## 원래 2분할 구성으로 돌아갈 때

양쪽에 원래 구성의 settings-reset을 적용한 뒤 백업한 `modu_left.uf2`,
`modu_right.uf2`를 각쪽에 설치해서 새로 연결합니다.
Corne 동글 복구도 기존 Corne 설정의 초기화/페어링 절차가 필요할 수 있습니다.
동글용과 원래 2분할용 펌웨어를 서로 다른 반쪽에 섞어 쓰지 마세요.

## 적용 전 마지막 확인

이 저장소를 만든 환경에서는 ZMK/Zephyr 전체 컴파일과 실물 시험을 하지 못했습니다.
GitHub Actions 실패 로그가 있으면 해결 전에는 기존 정상 펌웨어를 교체하지 마세요.
물리 리셋 진입을 확보하지 못한 상태에서도 초기화용 이미지를 먼저 넣지 마세요.
